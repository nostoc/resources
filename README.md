## Solidity Learning Resources


I found [CryptoZombies](https://cryptozombies.io/) to be a great resource for learning Solidity. It provides interactive lessons that guide you through building your own blockchain-based game, which makes the learning process engaging and practical. I came across this site while doing [Blockchain Specialization](https://www.coursera.org/programs/she-codes-too-jxaj0/specializations/blockchain) course on coursera.

There are [several courses](https://cryptozombies.io/en/course/) in CryptoZombies, I started with the first course [Solidity: Beginner to Intermediate Smart Contracts](https://cryptozombies.io/en/solidity). I find it very interesting.
